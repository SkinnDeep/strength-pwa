⏱️ Protocol Rest Standards

  • Squats & Presses: Rest 2 minutes between sets.
  • Deadlifts (RDL): Rest 90–120 seconds between sets.
  • Rows & Pulldowns: Rest 60–90 seconds between sets.
  • Carries, Calf Raises & Core: Rest 60 seconds.
  • One-sided exercises: Do both sides, then rest. Take 15–30s to switch sides if needed.
  • Equipment changes: Count as rest between exercises. Start your first set as soon as you set up at the new station.

📋 General Rules

  • DB: DB = dumbbell. DB weights are per hand unless labeled “total”.
  • Effort (RIR): Finish each lifting set with about 2 good reps left (RIR 2).
  • One-sided exercises: Do both sides, then rest. Take 15–30s to switch sides if needed.
  • Equipment changes: Serve as the rest between different exercises—start your first set as soon as you set up at the new station.
  • Time budget priority: Never rush reps to beat the clock. If behind schedule, skip the final carry/core set.
  • Pain stop rule: Sharp or joint pain: stop immediately and substitute or change the movement.

⏱️ Time Budget Allocation

  • Warmup: 6 minutes (3m walk/bike + 1m dynamic mobility + 2m practice sets).
  • Strength: ~27 minutes (including rest periods and station transitions).
  • Cardio: 7 minutes (conversational effort).
  • Cooldown: 5 minutes (2m gradual slow-down + 3m calf, hip, and chest stretches).
  • Session Total: Target 45 minutes; maximum 49 minutes.

📈 Progression Strategy

  • First 2 weeks: Only 2 working sets wherever 3 are listed (toggle on top).
  • 2-Session Top Rep Rule: When all sets reach the top of the rep range with good form for 2 consecutive sessions, increase by the smallest available weight increment.
  • Reset rep range: After increasing weight, return toward the lower end of the rep range.
  • Carries: Build from 30 to 45 seconds, then increase weight and return to 30 seconds.
  • Deload: If recovery or performance worsens, reduce a set or lower weight temporarily.
